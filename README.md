# Sheep_Flight_Management_Sim
My final project for my programming module year 1 term 1 of uni. A flight management simulator where you can create new flights, alter flights, cancel flights and delay flights. All sheep themed!

I received a 62/80 for this project (low first) and tried to utilise all I had been taught. In some places I've used a more roundabout solution rather than something straightforward, just so I could show off what I knew to my lecturers.
